## v1.0.1 — 2026-10-20
- 글 디자인 시안을 깔끔한 10종으로 새로 정리 (흰 바탕·포인트색 하나, 파스텔 상자 없음)
- 쿠팡·아고다·쇼핑커넥트 썸네일 배치 10종과 광고 고지 배너를 새 모양으로
- 사진 유사도 처리 테두리를 1px 연한 선으로 바꾸고 광고 그림에는 넣지 않음
- 계정 카드 [정지]는 계정은 그대로 두고 작업만 멈춤 (순서를 기다리던 작업도 함께 취소)
- 새 버전 exe 를 같은 폴더에 넣으면 계정·설정을 그대로 불러옴
- 폰트·아고다 기본 호텔 목록을 첫 실행 때 자동으로 받음
- 젠스파크·구글 플로우 로그인을 카모폭스 창으로 열고 로그인 완료를 자동 확인
- 서이추·스댓공은 구매한 경우에만 계정 설정에 표시
- 작업이 실패하면 오류 보고를 자동으로 보내고 실패 이유를 작업 로그에 표시
- 필수 이미지를 못 만들면 다른 그림으로 대체하지 않고 이유와 함께 그 글을 멈춤
- 도움말 최신화, 공통 안정성 개선
