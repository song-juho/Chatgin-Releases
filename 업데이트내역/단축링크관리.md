# 단축 링크 관리 업데이트 내역
<!-- app_id: short_link_manager -->

## v1.0.0 — 2026-10-03
- 단축 링크 조회 및 목적지 변경 관리 앱 출시
- Short.io API 키를 앱 전용으로 암호화 저장
- 도메인 선택 후 월·검색 조건으로 링크 조회
- 선택한 링크의 목적지 변경을 계획→실행→검증 3단계로 검증
- 변경 계획은 10분 유효, 1회만 실행 가능
- 조회 결과를 JSON·CSV로 내보내기
- 공통 인프라 개선 (작업 관리, 임시 파일 정리, 업데이트, 파트너사 연동)
